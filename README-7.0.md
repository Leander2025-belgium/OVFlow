# OVFlow 7.0 — Reference Design

Frontend-redesign op basis van de aangeleverde OVFlow-mock-up.

## Inbegrepen
- Nieuwe premium Home met OVFlow-wave-logo, zoekbalk, snelkoppelingen, lokale kaart en functies.
- Navigatie: Home, Reizen, Kaart, Tickets, Meer.
- Bestaande OVFlow routeplanner, haltezoeker, live vertrekdata, kaart en live-linkfunctionaliteit behouden.
- Ticketscherm in dezelfde visuele stijl.
- Bestaande standalone Live-pagina inbegrepen.
- PWA cache/versioning bijgewerkt.

## Installatie
Pak de ZIP uit bovenop de huidige OVFlow frontend. Deze ZIP bevat **geen backend server.js** en overschrijft de OVFlow API-backend dus niet.

Na upload op iPhone/PWA: sluit de app volledig af of ververs één keer zodat service-worker cache 7.0 actief wordt.
