# OVFlow Live 6.0 — Premium Live

Frontend upgrade on top of Live 5.7.

- Pixel-aligned mobile layout.
- 6–9 stop rows visible on common iPhones; 5 remains the hard floor on shorter devices.
- Timeline fills the full remaining viewport and all remaining stops stay scrollable.
- Distance to the next stop uses the GTFS shape first and direct GPS distance as fallback.
- Current/next stop semantics remain from 5.7.
- Initial map framing shows the current live segment; Route still fits the whole route.
- All existing API, route, vehicle, GTFS and De Lijn functionality is preserved.
